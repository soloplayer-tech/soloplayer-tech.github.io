CASE 01

스킬 설정과 슬롯 배치 분리

문제·요구사항
스킬 선택이나 슬롯 배치가 바뀔 때마다 설정을 중복 관리하지 않도록 데이터와 입력 연결을 나눌 필요가 있었습니다.
구현과 판단
Data Asset에 스킬 설정을 두고 Database에서 SkillID로 조회합니다. None ID와 비어 있는 항목을 처리하고 중복 ID에는 경고를 남깁니다. 이동·공격·슬롯·쿨다운 UI를 플레이어 흐름에 연결했습니다.

구현 범위와 확인 항목

  • None ID에 nullptr 반환
  • 비어 있는 Data Asset 제외·중복 ID 경고
  • 팀원과 제출 범위를 조정하고 플레이어 핵심 기능 우선 마무리
