CASE 01

맵 전환 뒤에도 이어지는 선택 정보

문제·요구사항
로비에서 전투 맵으로 이동하면 UI와 Pawn의 수명이 바뀌지만 플레이어의 팀·캐릭터 선택은 유지되어야 합니다.
구현과 판단
선택 정보는 PlayerState에 두고 CopyProperties·OverrideWith로 전달합니다. 서버에서 선택값을 변경하고 복제된 상태를 UI와 연결하며, 전투 맵에서 캐릭터 ID에 맞는 Pawn을 결정합니다.

구현 범위와 확인 항목

  • TeamID·TeamIndex·SelectedCharacterId·bReady 전달
  • Server RPC와 복제 상태를 통한 UI 연동
  • 팀·캐릭터 선택과 배틀존 입장 담당 커밋
핵심 코드 펼쳐 보기 ＋
NewPS->TeamID = TeamID;
NewPS->TeamIndex = TeamIndex;
NewPS->SelectedCharacterId = SelectedCharacterId;
NewPS->bReady = bReady;
PlayerState 코드 ↗담당 기능 커밋 ↗

현재 범위와 다음 확인

본인 담당 범위는 팀·캐릭터 선택 UI, 선택 요청, 관련 상태 전달과 전투 진입입니다. 전체 캐릭터 전투·경기 시스템을 모두 개인 구현으로 표시하지 않습니다.
