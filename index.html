03 / APPROACH

개발 방식

01

상태의 소유자와 수명

서버가 확정하는 값, UI가 표현하는 값, 맵 이동 후에도 유지할 값을 구분하며 시스템을 연결합니다.

02

실패 경로까지 확인

정상 동작 외에 부분 적용·빈 데이터·중복 입력 같은 경계를 살피고, 반복 확인할 항목은 테스트와 도구로 옮깁니다.

03

AI와 검증하며 개발

Codex·Claude Code를 코드 탐색과 구현·테스트 초안에 활용합니다. 변경된 코드와 실제 실행에서 확인한 범위를 구분합니다.
